# CF BAZA — сайт с админкой

Сайт клуба функциональной подготовки CF BAZA (Иркутск) и админ-панель, где всё содержимое меняется без программиста. Работает на Node.js без фреймворков. Данные и фото хранятся в PostgreSQL.

- **Сайт:** `/`
- **Админка:** `/admin`, логин `admin`
- **Заявки** сохраняются в админке и приходят письмом на почту из раздела «Уведомления о заявках» (по умолчанию Dadyfedor@yandex.ru). По желанию дублируются в Telegram.

## Переменные окружения

| Переменная | Зачем |
|---|---|
| `ADMIN_PASSWORD` | Пароль для первого входа. Потом меняется в админке. |
| `DATABASE_URL` | PostgreSQL. В Pipecore подставляется из подключённой базы. |
| `SMTP_USER`, `SMTP_PASSWORD` | Ящик, с которого уходят письма, и его пароль приложения. Для Яндекса: id.yandex.ru → «Безопасность» → «Пароли приложений» → «Почта». |
| `SMTP_HOST`, `SMTP_PORT` | По умолчанию `smtp.yandex.ru` и `465`. |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | Необязательно: заявки в Telegram. |

## Запуск на своём компьютере

```bash
npm install
ADMIN_PASSWORD=test12345 node server.js   # http://localhost:3000
```

Без `DATABASE_URL` всё хранится в файле `data/cfbaza.sqlite3`.

## Что где лежит

- `content.json` — описание полей админки и стартовое наполнение сайта.
- `lib/views.js` — HTML сайта и админки.
- `server.js` — маршруты, заявки, админка.
- `lib/db.js` — PostgreSQL или SQLite.
- `lib/mail.js` — отправка писем.
- `static/` — стили, скрипт, логотипы.

Новое поле в админке добавляется в `content.json`, а выводится на сайте в `lib/views.js`.
